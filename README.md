# SecureGuide.fr

Le radar des arnaques en France, en Belgique et au Luxembourg.

- `src/` : sources (pages, styles, alertes de la semaine dans `alerts.js`, guides dans `guides/`)
- `src/affiliate.json` : liens d'affiliation, à remplacer par les liens personnels
- `python3 build.py` : génère le site dans `dist/`, publié sur la branche `gh-pages`
